# 客户信息管理系统

> 一个零依赖、单文件的本地化客户账号管理工具。
> 打开 `index.html` 就能用，数据只存在你自己的浏览器里，不上传任何服务器（云同步可选）。

---

## 功能特性

- 📝 **客户信息管理** — 多平台账号、地区、医院、科室、学习进度、状态备注
- 🧩 **平台库自由配置** — 不再受限于预设平台，任意新增 / 重命名 / 删除
- 🔍 **多维筛选** — 平台 / 地区 / 医院 / 科室 四维组合叠加，类电商筛选体验
- 📋 **多选一键复制** — 批量勾选客户，按指定平台导出 `账号 密码` 格式
- 🔀 **批量编辑** — 一键改平台、地区、医院、科室、状态
- 📦 **本地导入 / 导出** — JSON 备份还原
- ☁️ **可选云同步** — 通过 GitHub Gist 在多设备间同步（**需自备 Token**）
- 📱 **PWA / 移动端可用** — 支持添加到主屏，离线可用
- 🔒 **隐私优先** — 数据默认仅存本地浏览器，不上传任何第三方服务器

## 30 秒上手

1. 打开网站（推荐 GitHub Pages 或本地双击 `index.html`）
2. 点右上角 **＋ 新增** → 录入第一位客户
3. **🎉 完成** — 你的所有数据已自动保存到浏览器

## ⚠️ 数据与隐私（重要，请先看）

| 问题 | 答案 |
|---|---|
| 数据存在哪里？ | **你浏览器的 localStorage**，不依赖任何服务器 |
| 分享仓库会泄露我的客户数据吗？ | **不会**。仓库里只有代码，没有数据文件 |
| 换电脑 / 清缓存会丢数据吗？ | **会**。请用「📦 导出」备份 JSON |
| 多设备同步怎么搞？ | 用可选的 ☁️ 云同步（GitHub Gist，**请用自己的 Token**） |
| Token 安全吗？ | Token 仅保存在你本地浏览器，本项目代码不外发它 |

## ☁️ 云同步说明（可选）

通过 GitHub Gist 在多设备间同步数据，**你必须使用自己的 GitHub Token 和自己的 Gist ID**，不要使用他人的凭据。

### 配置步骤

1. 创建 GitHub Token：`https://github.com/settings/tokens` → Generate new token (classic)
   - 勾选权限：**`gist`**（最小权限就够）
   - 复制生成的 `ghp_xxx...` Token
2. 打开本工具 → ☁️ 云同步 → 粘贴 Token
3. 点 **「☁️ 上传到云」** — 自动创建一个 Gist 并上传你的数据
4. **复制显示出来的 Gist ID**（其他设备需要它）

### 在另一台设备同步

1. 同样打开本工具 → ☁️ 云同步
2. 填入**同一个** GitHub Token 和 **同一个** Gist ID
3. 点 **「☁️ 从云下载」** — 数据拉取到本设备

### ⚠️ 同步注意事项

- 上传会**覆盖**云端数据，多设备操作请遵循：**用之前先下载，用完立刻上传**
- 不要把 Token 分享给他人 = 不要把账号钥匙给出去
- 不要在别人的仓库或来源不明的网页里填入你的 Token

## 🧩 平台库管理

工具栏 **🧩 平台管理** 按钮：

- **新增**：任意命名，不局限于双卫 / 医博士等
- **重命名**：自动同步更新所有客户的平台名
- **删除**：仅从下拉中移除，**不会**损坏已有客户数据

新增客户时，下拉旁有 **+ 新建** 输入框，可直接把新平台加入平台库。

---

## 📋 多选一键复制账号密码

1. 进入 **☑ 批量操作**
2. 勾选多个客户
3. （可选）在 **📋 复制所选账号密码** 旁边的平台下拉里选择要复制的平台
4. 点 **📋 复制所选账号密码**

输出格式（账号密码之间一个空格，每行一组）：

```
zhangsan01 Aa111111
lisi02 Cc333333
```
